# Sales Analysis Dashboard

## 1. Project Line
An interactive Sales Analysis Dashboard created using Microsoft Power BI Desktop as part of Task 3 of the CodeOrbit Tech Data Analyst Internship. It presents key sales metrics and helps explore sales trends, profit, product categories, customer segments, and shipping performance.

**Dataset:** Public SuperStore Sales dataset from Kaggle, used for learning and practice. This is not official CodeOrbit company data.

## 2. Technologies Used
- Microsoft Power BI Desktop
- Power Query for data preparation
- Data visualization and dashboard design
- SuperStore Sales dataset from Kaggle

## 3. Setup Instructions
1. Download or clone this GitHub repository.
2. Install Microsoft Power BI Desktop.
3. Open `Sales_Analysis_Dashboard.pbix` in Power BI Desktop.
4. Explore the KPI cards, charts, and interactive filters.
